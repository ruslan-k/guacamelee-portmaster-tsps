Conclusion
----------
This run does not prove whether VideoSys.cpp:1644's 0x502 is genuine because
clean Box64 crashes before reaching it. It does prove that the clean diagnostic
configuration itself reaches SDL context creation and complete corrected FBO
checks, then fails at fclose(NULL). The old 0x502 must not be ranked as a clean
baseline result until this early Box64 crash is removed or a validated Box64
variant reaches the scene without behavior-changing render instrumentation.
