## Program21 composition

The program trace shows program21 linked/used after guest shaders 19 and 20:

```text
shader19: fragment, compile status=1
shader20: vertex, compile status=1
program21: link=1, use=1
```

The captured original shader source for shader19 is:

```glsl
#version 120
uniform vec4 vMult;
varying vec4 v_texcoord0;
void main()
{
    gl_FragColor = vMult;
}
```

The captured vertex source for shader20 includes:

```glsl
varying vec4 v_texcoord0;
void main()
{
    gl_Position = vec4(0.0, 0.0, 0.0, 1.0);
    v_texcoord0 = vec4(0.5, 0.5, 0.5, 0.5);
}
```

The same guest shader ID is later reused for a fragment shader containing `sampler2D sampler0`, `vMult`, and `vAdd`; allocation/ID reuse must therefore be tracked by compile/link chronology and not by numeric shader ID alone.
