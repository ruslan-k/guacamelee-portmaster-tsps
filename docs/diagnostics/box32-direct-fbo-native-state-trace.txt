```text
logical=1 native=1 requested=0x8056 actual=0x8056 1280x720
```

The first logical FBO still reports `0x8cd7` after color-only setup and `0x8cdd` after depth/stencil setup. Texture-backed FBOs 2–5 report `0x8cd7`. The expected `TEX_ATTACH_POST` marker did not appear, so the texture post-query branch is not yet proven and must be corrected separately; this absence is recorded rather than interpreted as `GL_NONE`.

The game stayed alive through the run and FMOD reported `FMOD init succeeded with driver 1`.

Conclusion: native controls are complete, gl4es creates real native renderbuffers/attachments, and the remaining issue is in the texture attachment/state path or later render pass. No production library was replaced.
