
No X11 stub function was used. The game then reached shader bootstrap and failed at the next boundary:


The file is not present as a loose shader. `gamedata` contains `shaders.dat.ogl` (330406 bytes), while the direct working directory is the port root. No first game draw or visible title frame was reached in this run. This is now a shader asset/path or game shader-loader boundary, followed by a separate Box64 `fclose(NULL)` error-path crash; no additional workaround was added.

The temporary direct process was terminated exactly and SpruceOS UI was restored afterward.
