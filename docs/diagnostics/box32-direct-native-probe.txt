# Stage 1 native AArch64 SDL/KMSDRM probe

Status: NOT RUN — build blocked before producing a binary.

The source is `experiments/box32-direct/src/native_probe.c`. It was updated to query `eglGetCurrentDisplay`, `eglGetCurrentContext`, `eglGetCurrentSurface(EGL_DRAW/READ)` after SDL context creation.

Attempted build environment: an initial Ubuntu 20.04 container without the multiarch setup stalled in `apt-get install` for 420 seconds; `/tmp/probe-build` remained empty. This was superseded by the successful multiarch Dockerfile.64-derived build documented below.

Required next run: build with a cached/pinned compatible toolchain, then execute on TSPS with only native SDL2/EGL/GLES, `SDL_VIDEODRIVER=KMSDRM`, and capture physical magenta while 120 swaps are active.

Per the prescribed stop condition, i386 Box32/gl4es probes and the NULL-display patch deployment were not run after this failure. The direct Box32 issue is not currently actionable until native SDL/KMSDRM scanout is repaired or its ownership/DRM page-flip behavior is explained.
