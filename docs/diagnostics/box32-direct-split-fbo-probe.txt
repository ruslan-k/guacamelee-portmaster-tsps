Test 1 clears FBO A to (64,128,191,255), blits READ=A to DRAW=B, and reads B.
The expected non-black pixel is preserved.

Test 2 clears default FBO0 to a different red color while leaving A unchanged,
then blits READ=A to DRAW=B. B correctly remains the original A color. This
proves the split READ/DRAW semantics and confirms that the read source selection
is respected; the result is not a generic gl4es split-FBO failure.

Rejected preliminary run
------------------------
A first attempt without LIBGL_NOTEST had maxcolorattach=0, produced 0x506 and
failed the probe. It was configuration-mismatched and is not used as evidence.
A second attempt with SDL_VIDEODRIVER=auto failed at SDL_Init because the direct
probe had no initialized display path. It was also rejected. The KMSDRM run above
is the valid result.
