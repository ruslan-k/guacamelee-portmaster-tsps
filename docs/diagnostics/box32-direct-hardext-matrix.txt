## Matrix classification

`maxcolorattach=1` is a real required NOTEST initialization. `depthstencil=1` independently removes the FBO/0x506 failure. Neither makes the game visible. Normal detection is not usable on this direct SDL/KMS path without a separate EGL loader fix.

All temporary device processes/files were removed after each run. `principal.sh` and MainUI remained running. Production state was left untouched.
