## Result

PASS. Keeping the original binary in the same `gamedata/` directory as `shaders.dat.ogl` restores the normal Linux asset-base semantics. The old `box32-direct/game-bin` path was an invalid layout for this title and must not be used.

The current shipping experimental launcher already uses:

```text
DATADIR=$GAMEDIR/gamedata
GAME=$DATADIR/game-bin
cd $DATADIR
```

The next blocker is therefore no longer shader asset lookup. It remains the later FBO/render/presentation transition, with native FBO controls complete, real gl4es draw events proven, and exact SDL swap invocation still unproven.
