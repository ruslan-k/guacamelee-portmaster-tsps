because a pointer value was invalid. That run is rejected as runtime evidence.

because an unrelated production ARMHF game process was already holding DRM.

crash and are valid only as observations emitted before the crash. The guarded
implementation must be rerun in an idle DRM state for a clean no-crash confirmation.
